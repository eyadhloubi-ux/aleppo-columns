# رسائل إلى أبناء حلب

عرض تقديمي تفاعلي لمقترح رسائل أعمدة ساحة التحرير في حلب (4 شرائح).

## الملفات
- `index.html`: صفحة العرض
- `css/style.css`: التنسيق
- `js/main.js`: التنقل بين الشرائح
- `assets/img/`: صورة العمود النموذجية (وبدقة كاملة)، وتصميما اللوحتين الكبيرة والصغيرة، والأيقونة
- `render.yaml`: إعداد النشر على Render

## التنقل
شريحة شريحة: أزرار الأسهم أسفل الشاشة، أو السحب باللمس، أو عجلة الماوس، أو أسهم لوحة المفاتيح. يعمل على الكمبيوتر والموبايل والتابلت.

## النشر على Render
1. ارفع محتوى هذا المجلد إلى جذر مستودع جديد على GitHub.
2. في Render اختر **New > Blueprint** واربط المستودع، فيقرأ `render.yaml` وينشر الموقع كموقع ثابت.
