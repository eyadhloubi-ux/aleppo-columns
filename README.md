# أعمدة تحكي حلب

عرض تقديمي تفاعلي لمقترح وضع صور شخصيات حلبية على أعمدة ساحة التحرير في حلب، معدّ لعرضه على محافظة حلب.

## المحتوى
- `index.html`: صفحة العرض (4 شرائح).
- `css/style.css`: التنسيق.
- `js/main.js`: التنقل بين الشرائح والتبديل بين الشخصيتين.
- `assets/img/`: صور الرندر بعد تركيب اللوحات، وصور الشخصيات.
- `render.yaml`: إعداد النشر على Render.

## التنقل
- السكرول بالماوس أو باللمس.
- أزرار الأسهم أسفل الشاشة.
- أسهم لوحة المفاتيح ومفتاح المسافة.

يعمل على الكمبيوتر والموبايل والتابلت، ولا يحتاج أي بناء أو تثبيت.

## النشر على Render
1. ارفع محتوى هذا المجلد إلى مستودع جديد على GitHub (الملفات في جذر المستودع مباشرة).
2. في Render اختر **New > Blueprint** واربط المستودع.
3. سيقرأ Render ملف `render.yaml` وينشر الموقع كموقع ثابت (Static Site) مجاناً.

## النشر على GitHub Pages (بديل)
من إعدادات المستودع: **Settings > Pages**، ثم اختر الفرع `main` والمجلد `/ (root)`.

## التجربة محلياً
افتح `index.html` مباشرة في المتصفح.
